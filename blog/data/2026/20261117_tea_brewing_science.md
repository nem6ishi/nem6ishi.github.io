「熱湯で淹れる」「ポットを温める」「蓋をして蒸らす」「ティーバッグは絞らない」——紅茶の淹れ方にはさまざまなお約束がありますが、その多くは**食品化学・熱力学・流体力学**の観点から説明がつきます。

一方で、「再沸騰したお湯は酸素が抜けてジャンピングしない」のように、科学的に検証すると少しニュアンスが異なる定説もあります。この記事では、美味しい紅茶を淹れるための基本レシピと、その背景にある科学的な仕組みを整理しました。

---

## 1. 基本のストレートティー（黄金比）

まずは再現性の高い基本レシピです。

| 項目 | 目安（1〜2杯分） | 科学的な理由 |
| :--- | :--- | :--- |
| **水質** | **軟水**（日本の水道水でOK） | ミネラルによる水色の暗化・茶渋膜を防ぐ |
| **水温** | **95〜100℃**（沸騰直後） | 香気成分の揮発とテアフラビンの抽出を促す |
| **比率** | 茶葉 **2.5〜3 g** / 湯 **150〜180 ml** | 香り・コク・キレのバランスが整う濃度域 |
| **時間** | 細かい葉：**1.5〜2.5分** / 大きい葉：**3〜4分** | 高分子タンニンが過剰に出る前に引き上げる |

1. **予熱する**：ポットとカップに少量のお湯を注いで温め、湯を捨てる。
2. **お湯を注ぐ**：計量した茶葉を入れ、汲みたての軟水を沸騰直後に勢いよく注ぐ。
3. **蒸らす**：すぐに蓋をして、茶葉のサイズに合った時間だけ静かに待つ。
4. **注ぎ切る**：茶漉しを通し、濃度が均一になるよう最後の一滴まで注ぎ切る。

## 2. 抽出の化学：お湯の中で何が起きているのか

### 成分によって溶け出すスピードが違う

紅茶の抽出は、茶葉（固相）から水（液相）へ可溶性成分が移動する**固液抽出**です。各成分の溶出速度はおおむね次の一次速度式に従います。

$$\frac{dC_t}{dt} = k(C_s - C_t)$$

ここで $C_t$ は時間 $t$ における液中の濃度、$C_s$ は飽和濃度、$k$ は抽出速度定数です。分子が小さく水になじみやすい成分ほど $k$ が大きく、お湯を注いだ直後から素早く溶け出します。

| 成分群 | 味・香り・色への寄与 | 抽出の挙動 |
| :--- | :--- | :--- |
| **揮発性香気成分**<br>（リナロール、ゲラニオール等） | 花のような華やかな香り | **90〜100℃**で揮発性と拡散速度が大きく高まる |
| **カフェイン** | 爽やかな苦味・キレ | **0〜2分**で急速に溶出する（$k$ が大きい） |
| **アミノ酸・糖類** | 旨味・甘味・まろやかさ | 温度を問わず比較的速やかに溶出する |
| **テアフラビン類** | 鮮やかな橙赤色・心地よい渋味 | 高温でよく溶け出し、**2〜5分**でバランスが整う |
| **テアルビジン・高分子タンニン** | 深い赤褐色・強い渋味（収斂味） | 分子が大きくゆっくり拡散し、**4〜5分以降**も溶出し続ける |

この溶出スピードの差から、「熱湯・予熱・蓋・時間管理」の理由が説明できます。

* **熱湯＋ポット予熱**：冷たいポットに熱湯を注ぐと、器に熱を奪われて水温が一気に80℃台まで下がります。予熱でヒートロスを防ぎ90℃以上を保つことで、茶葉の細胞壁が緩み、香気成分とテアフラビンが効率よく抽出されます。
* **蓋をする**：香りを担うリナロールなどは揮発性が高く、開放状態では湯気とともに逃げてしまいます。蓋をすることでポット内の空間（ヘッドスペース）に香気を閉じ込めます。
* **2〜4分で引き上げる**：抽出が長引くほど、香気やテアフラビンの増加が頭打ちになる一方で、高分子タンニンの割合が増え続けます。

> **💡 渋味（収斂味）の正体**  
> 紅茶の強い渋味は味覚ではなく、高分子タンニンが**唾液中のタンパク質と結合・沈殿して口内の潤滑を奪う「触覚的な刺激」**です。規定時間で茶葉を引き上げるのは、この過剰なタンニンを切り捨てるためです。

### 茶葉の形状（ホールリーフ vs CTC）と表面積

同じ茶葉でも、加工形状によって固液接触の**表面積／体積比**と、水が細胞内部へ浸透する距離が変わります。

* **オーソドックス製法（OPなどの大きい葉）**：葉の細胞構造が保たれており表面積が小さいため、成分が拡散するまで**3〜4分**かかりますが、繊細な香りが出やすいのが特徴です。
* **CTC製法（細かく丸めた葉）・ブロークン（BOP）**：製造時に細胞壁が細かく破壊され、表面積が非常に大きい状態です。速度定数 $k$ が高いため、**1.5〜2.5分**の短時間で濃厚な液が得られます（ミルクティー向き）。

> **📌 豆知識：国際規格「ISO 3103」**  
> 紅茶の官能評価（テイスティング）用の国際規格 ISO 3103 では「沸騰水100 mlあたり茶葉2 g、抽出6分」と定められています。これは品質の差や欠点をあぶり出すための厳しい試験条件であり、日常の飲用では2〜4分が適しています。

## 3. 水とポットの物理学

### 硬水と「茶渋膜（Tea Scum）」の化学

冷めた紅茶の表面に浮く虹色の薄い膜は油ではなく、カルシウムイオン（$\text{Ca}^{2+}$）とポリフェノールが結合した**茶渋膜（Tea Scum、厚さ約20 nmの有機金属錯体）**です。

紅茶の抽出液は本来弱酸性（pH 5前後）ですが、硬水に含まれる炭酸水素イオン（$\text{HCO}_3^-$）には酸を中和してpHを上げる緩衝作用があります。また、加熱によって次の平衡反応も進行します。

$$\text{Ca}^{2+} + 2\text{HCO}_3^- \xrightarrow{\Delta} \text{CaCO}_3\downarrow + \text{CO}_2\uparrow + \text{H}_2\text{O}$$

pHが高い状態では、ポリフェノールのヒドロキシ基（$-\text{OH}$）がイオン化しやすくなり、水中の $\text{Ca}^{2+}$ と架橋結合して水面に膜を作ります。この膜は香りの立ち上がりを塞ぐうえ、ポリフェノールが消費されるため水色も黒ずんでしまいます。

* **日本の水道水が向いている理由**：日本の水道水は多くが軟水（硬度30〜80 mg/L程度）のため、茶渋膜ができにくく、澄んだ赤色と香りを引き出せます。
* **レモンで色が明るくなる理由**：レモン汁（クエン酸）から供給される水素イオン（$\text{H}^+$）がポリフェノールを元の状態に戻し、$\text{Ca}^{2+}$ との結合を解くため、膜が消えて水色が明るい黄色〜橙色へ変化します。

### 「再沸騰すると酸素が抜けてダメ」は本当か？

「一度沸かしたお湯を再沸騰させると、溶存酸素が抜けてジャンピングしなくなる」とよく言われます。しかし、気体の水への溶解度は水温が上がるほど低下し、**1度目の沸騰（100℃）に達した時点で溶存酸素はほぼゼロ**になります。つまり、沸騰時点での酸素量は1回目でも2回目でもほとんど変わりません。

それでも「汲みたての水・沸かしすぎない湯」が推奨される本当の理由は次の2点です。

* **ミネラルの濃縮**：長時間沸かし続けたり何度も煮詰めたりすると、水分が蒸発して $\text{Ca}^{2+}$ などの硬度成分が濃縮され、茶渋膜や雑味の原因になります。
* **pHの変化**：溶存していた二酸化炭素（$\text{CO}_2$）が完全に抜けることで水のpHがわずかにアルカリ側へ傾き、抽出バランスや水色に影響します。

### ジャンピングと丸型ポットの流体力学

ポットの中で茶葉が上下する「ジャンピング」は、溶存酸素だけによるものではなく、3つの物理現象が重なって起きています。

1. **熱対流**：ポット壁面で少し冷えたお湯が沈み、中心部の熱いお湯が昇る自然対流。
2. **微細気泡の浮力**：注湯時に巻き込まれた空気や、乾いた茶葉表面の凹凸に残っていた微小な空気泡が茶葉を浮き上がらせる力。
3. **吸水による沈降**：水面で気泡が外れると、水を吸って重くなった茶葉が底へ沈み、再び対流に乗って舞い上がるサイクル。

丸型（球状）のポットが好まれるのは、角がないことで流体力学的な抵抗が減り、対流がスムーズに循環するためです。

## 4. アイスティーとミルクティーの科学

### クリームダウン（白濁）と2つの対策

熱い紅茶を冷やしたときに白く濁る現象を**クリームダウン（Tea Cream）**と呼びます。温度が下がると、平面的な構造を持つ**テアフラビン**同士が疎水性相互作用（$\pi\text{-}\pi$ スタッキング）で集まって約3 nmのナノクラスターを作り、そこに**カフェイン**が水素結合で入り込んで光を散乱する大きなコロイド粒子へと成長するためです。

* **オンザロック急冷法**：氷を入れたグラスに熱い紅茶を注いで急冷すると、分子が大きな会合体へ成長する時間を与えず、過飽和のまま透明感を保てます（ただし濃く淹れすぎると濁りやすくなります）。
* **水出し（コールドブリュー）**：冷水ではそもそもカフェインやテアフラビンの抽出量が少なく、白濁が起きる濃度に達しません。渋味が抑えられ、低温でも溶け出すアミノ酸の甘味が際立つクリアな味になります。

### ミルクティー：「ミルク先入れ」vs「紅茶先入れ」

牛乳のタンパク質の約80%を占める**カゼイン**は、紅茶のタンニンと結合して包み込み、舌の上で渋味を感じさせなくする**マスキング効果**を持っています。

英国で長年議論されてきた「ミルクが先か、紅茶が先か」には、それぞれ明確な根拠があります。

* **ミルク先入れ（英国王立化学会 RSC の推奨）**：熱い紅茶（90℃以上）に冷たいミルクを後から垂らすと、少量のミルク滴が局所的に高温へ晒され、乳タンパク質が熱変性して加熱臭や微細なダマを生じやすくなります。先にミルクを入れておけば、注がれる紅茶によって全体の温度が緩やかかつ均一に上がるため、滑らかな風味が保たれます。
* **紅茶先入れ（実用上のメリット）**：紅茶の水色と濃さを見極めながら、最適なミルクの量を微調整できる利点があります（紅茶先入れにする場合も、ミルクを冷やしすぎないことで温度ショックを和らげることができます）。

## 5. よくある疑問 Q&A

### Q. ティーバッグは「振る」「絞る」とダメ？

**A. ストレートで飲むなら避け、ミルクティーなら絞ってもOKです。**

静止したお湯の中では茶葉の周囲に高濃度の層（**境界層**）ができて抽出が穏やかになりますが、激しく振ると境界層が壊れて抽出が急進し、微粉（ダスト）も漏れ出て濁りやすくなります。また、引き上げたバッグ内に残る少量の液には、後半に溶け出した**高濃度のタンニン**が凝縮されています。ストレートではえぐみの原因になりますが、ミルクティーならカゼインが渋味を中和するため、絞ってコクを足すのも合理的です。

### Q. 金属製のヤカンやスプーンは避けるべき？

**A. 鉄瓶は避け、現代のステンレス製なら問題ありません。**

ポリフェノールは鉄イオン（$\text{Fe}^{2+}$ / $\text{Fe}^{3+}$）と反応すると黒紫色の錯体（**タンニン鉄**）を作り、水色が黒ずんで金属味を帯びます。鉄分が溶出する鉄瓶は紅茶には不向きですが、表面が不動態皮膜で守られたステンレス製のケトルやスプーンであれば金属イオンはほぼ溶出しないため、安心して使えます。
