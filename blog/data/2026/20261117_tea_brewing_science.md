「熱湯で淹れる」「ポットを温める」「蓋をする」「ティーバッグは絞らない」——紅茶の淹れ方にはさまざまなお約束がありますが、その多くは**食品化学・熱力学・流体力学**の観点から見ても理にかなっています。

この記事では、美味しい紅茶を淹れるための基本レシピと、その裏側にある科学的な仕組みを端的にまとめました。

---

## 1. 基本のストレートティー（黄金比）

まずは再現性の高い基本レシピです。

| 項目 | 目安（1〜2杯分） | ポイント |
| :--- | :--- | :--- |
| **水質** | 軟水（日本の水道水でOK） | ミネラルによる渋味・濁りを防ぐ |
| **水温** | 95〜100℃（沸騰直後） | 香気成分とテアフラビンの抽出効率を最大化 |
| **比率** | 茶葉 **2.5〜3 g** / 湯 **150〜180 ml** | 香り・コク・キレのバランスが最も良い |
| **時間** | 細かい葉：**2〜3分** / 大きい葉：**3〜4分** | 高分子タンニンの過剰溶出前に引き上げる |

**手順**：ポットとカップを少量のお湯で**予熱** → 汲みたての軟水を**沸騰直後**に勢いよく注ぐ → **蓋**をして規定時間待つ → 茶漉しで**最後の一滴まで**注ぎ切る。

## 2. 抽出の化学：お湯の中で何が起きているのか

紅茶の抽出は、茶葉（固相）から水（液相）へ成分を移す**固液抽出**です。溶出速度はおおむね次の式で表されます。

$$\frac{dC_t}{dt} = k(C_s - C_t)$$

（$C_t$：時刻 $t$ の濃度、$C_s$：飽和濃度、$k$：成分ごとの抽出速度定数）

成分によって分子サイズが異なるため、お湯に溶け出す順番とスピードに差が出ます。

| 成分群 | 味・香り・色への寄与 | 溶出のタイミング |
| :--- | :--- | :--- |
| **香気成分**（リナロール等） | 花のような香り・甘い芳香 | 90〜100℃で揮発性と拡散速度が急上昇 |
| **カフェイン** | 爽やかな苦味・キレ | **0〜2分**で極めて速く溶出（$k$ が大きい） |
| **アミノ酸・糖類** | 旨味・甘味・まろやかさ | 低温〜高温まで比較的速やかに溶出 |
| **テアフラビン類** | 鮮やかな橙赤色・心地よい渋味 | 高温で効率よく抽出され、**2〜6分**でピークへ |
| **テアルビジン・高分子タンニン** | 深い赤褐色・強い渋味（収斂味） | 分子が大きく、**8分以上**で相対比率が増える |

> **💡 なぜ「熱湯・予熱・蓋・2〜4分」なのか**  
> * **熱湯＋予熱**：冷たいポットに注ぐと水温が一気に80℃台まで落ちるため、予熱でヒートロスを防ぎ、高温で細胞壁を緩めて拡散を促します。  
> * **蓋をする**：揮発性の高い香気成分が蒸気と一緒に逃げるのを防ぎ、ポット内に香りを閉じ込めます。  
> * **時間で区切る**：渋味の正体は、高分子タンニンが唾液中のタンパク質と結合・沈殿させて口内の潤滑を奪う反応です。長時間の抽出は、香気成分が頭打ちになったあとにタンニンばかりを増やしてしまいます。

### 茶葉の形状と表面積の法則

* **オーソドックス（OPなど大きい葉）**：細胞構造が保たれており表面積が小さいため、ゆっくり（3〜4分）抽出すると繊細な香りが出ます。
* **CTC（細かく丸めた葉）**：細胞壁が破壊され表面積が大きいため、抽出速度定数 $k$ が高く、短時間（1.5〜2分）で濃厚な液になります（ミルクティー向き）。

※ちなみに、国際的な官能評価規格 **ISO 3103** では「沸騰水100 mlあたり茶葉2 g、6分抽出」と定められていますが、これは品質評価用の濃い基準です。

## 3. 水とポットの物理学

### 硬水と「茶渋膜（Tea Scum）」の化学

冷めた紅茶の表面に浮く虹色の膜は油ではなく、カルシウムイオン（$\text{Ca}^{2+}$）とポリフェノールが結合した有機金属錯体（厚さ約20 nm）です。硬水に含まれる炭酸水素イオン（$\text{HCO}_3^-$）が加熱されると次の反応が進み、pHが上がって錯形成が起きやすくなります。

$$\text{Ca}^{2+} + 2\text{HCO}_3^- \xrightarrow{\Delta} \text{CaCO}_3\downarrow + \text{CO}_2\uparrow + \text{H}_2\text{O}$$

* **日本の水道水（軟水）は紅茶向き**：硬度が低いため茶渋膜ができにくく、本来の明るい赤色と香りを保てます。
* **レモンで色が明るくなる理由**：クエン酸の $\text{H}^+$ によってポリフェノールが元の状態に戻り、$\text{Ca}^{2+}$ との結合が解かれるためです。

### 「再沸騰で酸素が抜けてダメ」の真実

「再沸騰したお湯は溶存酸素が抜けてジャンピングしない」とよく言われますが、物理化学的には**1度沸騰（100℃）した時点で溶存酸素はほぼゼロになるため、1回目と2回目で酸素量に実質的な差はありません**。

それでも「汲みたて・沸かしすぎない湯」が良い理由は、**長時間煮詰めることによるミネラル（硬度成分）の濃縮**と、**$\text{CO}_2$ が抜けることによるわずかなpH上昇（アルカリ化）**を避けるためです。

### ジャンピングと丸型ポット

茶葉が上下する「ジャンピング」は、**ポット内の温度差による熱対流**、**注湯時や茶葉表面の微細気泡による浮力**、**吸水して重くなった茶葉の沈降**のサイクルで起きます。丸型ポットが有利なのは、角がなく対流の流速を妨げないためです。

## 4. アイスティーとミルクティーの科学

### クリームダウン（白濁）と対策

熱い紅茶をゆっくり冷やすと白く濁るのは、**テアフラビン**同士が疎水性相互作用（$\pi\text{-}\pi$ スタッキング）で直径約3 nmのクラスターを作り、そこに**カフェイン**が水素結合で入り込んで大きなコロイド粒子へ成長するためです。

* **オンザロック急冷法**：氷で一気に冷やすことで、分子が大きな結晶・会合体へ成長する時間を与えず透明感を保ちます。
* **水出し（コールドブリュー）**：低温ではカフェインや高分子ポリフェノールの抽出量自体が少ないため白濁せず、アミノ酸由来の甘味が際立つクリアな仕上がりになります。

### ミルクティー：「ミルク先入れ」vs「紅茶先入れ」

牛乳の主成分タンパク質**カゼイン**は、紅茶のタンニンと結合して包み込むことで渋味を劇的に和らげます（マスキング効果）。

* **英国王立化学会（RSC）の見解は「ミルク先入れ」**：熱い紅茶に冷たいミルクを後から注ぐと、少量のミルクが局所的に高温へ晒されてカゼインが熱変性し、加熱臭やダマの原因になりやすいため、ミルクを先に入れて温度を緩やかに上げるのが推奨されています。
* **「紅茶先入れ」の利点**：紅茶の水色を見ながらミルクの量を微調整できる実用性があります。

味を優先するなら「ミルク先入れ（またはミルクを常温に近づける）」、濃さ調整を優先するなら「紅茶先入れ」が合理的です。

## 5. よくある疑問 Q&A

### Q. ティーバッグは「振る」「絞る」とダメ？

**A. ストレートは NG、ミルクティーならアリです。**

ティーバッグを激しく振ると茶葉周囲の飽和層（境界層）が壊れて抽出が急進し、終盤は微粉が抜け出て濁りの原因になります。また、引き上げたバッグ内の残留液には後半に溶け出した**高濃度のタンニン**が凝縮されているため、ストレートでは絞らないのが無難です。逆にミルクティーなら、カゼインが渋味を中和するため絞ってコクを出すのも有効です。

### Q. 金属製のヤカンやスプーンは避けるべき？

**A. 鉄瓶は避け、現代のステンレス製なら問題ありません。**

ポリフェノールは鉄イオン（$\text{Fe}^{2+}$ / $\text{Fe}^{3+}$）と反応して黒紫色の「タンニン鉄」を作り、色と風味を損ねます。鉄分が溶出する鉄瓶は不向きですが、不動態皮膜のあるステンレス製ケトルやスプーンなら影響はほぼありません。
