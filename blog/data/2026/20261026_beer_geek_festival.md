## ブルワリー詳細メモ

### 1. Brujos Brewing（ブルホス・ブルーイング）
* **拠点**: オレゴン州ポートランド
* **創業者 / ブルワー**: Sam Zermeño（元Great Notion Brewing）
* **Untappd ブルワリー評価**: **4.38**
* **背景**:
  * ポートランドやシカゴ等の各地ブルワリーで醸造を行うジプシー（ファントム）ブルワリーとしてスタート。
  * 熱狂的なカルト的人気を得て、2024年にポートランド・スラブタウンに待望の実店舗/タップルームをオープン。
  * 魔術・オカルト・ブラックメタルをモチーフにしたダークな世界観が象徴的。
* **代表銘柄・注目ビール**:
  * **Tres Maledicti**（Quadruple IPA / 12.0% / **Untappd: 4.60**）: 4種以上のホップを限界まで詰め込んだモンスター級クアッドIPA。濃厚なトロピカルフルーツ感とアルコールの温かみが完璧に調和。
  * **Infinitum**（IPA / 7.0% / **Untappd: 4.44**）: シングルIPAながら圧倒的なアロマの広がりを見せるフラッグシップ級ヘイジー。
  * **Populus / TDH Populus**（Hazy DIPA / 8.0% / **Untappd: 4.40**）: トリプルドライホップによる超濃厚なマンゴー・パイナップル香。
  * **Errementari**（Quadruple IPA / **Untappd: 4.50**）

### 2. Root + Branch Brewing（ルート・アンド・ブランチ）
* **拠点**: ニューヨーク州コピアグ（ロングアイランド）
* **創業者**: Anthony Sorice（元歴史学専攻修士、Threes Brewing / LIC Beer Project出身）、Ryan Mauban（NYの伝説的ビアバーTørst出身のCertified Cicerone）
* **Untappd ブルワリー評価**: **4.37**
* **背景**:
  * 2018年ジプシー開始、2022年にロングアイランドに自社醸造所＆タップルームを開業。
  * Other Half、Tree House、Fidens等と並び称される、**全米最高峰の濁りとアロマを極めたHazy IPA**の巨頭。
* **代表銘柄・注目ビール**:
  * **Artstar**（Imperial Hazy DIPA / 8.0% / **Untappd: 4.25**）: シルキーなオーツの口当たりと、熟したピーチ・メロンのような極上の果汁感。Hop Burn（喉への刺激）が一切ない至高の濁り。
  * **Medium Raw**（Triple Hazy IPA / 10.0% / **Untappd: 4.30**）: 重厚なボディと幾重にも重なるホップレイヤーが押し寄せる名作TIPA。
  * **The Castle**（Hazy Pale Ale / 5.5% / **Untappd: 4.20**）: 低アルコールながらダブルIPA顔負けのフレーバー密度を誇る傑作ペールエール。
  * **Life And Fate シリーズ**（Hazy DIPA / **Untappd: 4.35+**）: バッチごとにホップ構成が変わる哲学的フラッグシップ。

### 3. Everywhere Beer Co.（エブリウェア）
* **拠点**: カリフォルニア州オレンジ
* **創業者**: Jeremy Grinkey、Stefan Weber、Daniel Muñoz、Keith Pumilia
* **Untappd ブルワリー評価**: **4.10**
* **背景**:
  * バレルエイジドやサワーで世界に名を轟かせた**「The Bruery / Bruery Terreux」出身の精鋭4名**が2022年に設立。
  * 「クラフトビールはどこでも楽しめる、誰にでも届く」という哲学のもと、最高純度の醸造技術を展開。
* **代表銘柄・注目ビール**:
  * **another moment**（Hazy DIPA / 8.2% / **Untappd: 4.20**）: パッションフルーツやシトラスが炸裂する、南カリフォルニアらしい陽気でジューシーなヘイジー。
  * **balance**（West Coast IPA / 6.8% / **Untappd: 4.05**）: モダンなホップアロマとクリーンで研ぎ澄まされたドライな苦味の共存。
  * **everyone**（Kölsch / 4.8% / **Untappd: 3.90**）: ラガー・ケルシュとしては異例の超高評価。濁りビールの合間に挟むと感動するほど綺麗。

### 4. The TEST Brewery（テスト・ブルワリー）
* **拠点**: ニューヨーク州ブルックリン（ウィリアムズバーグ）
* **創業者**: Ben Clayton（ミシュラン星付きレストラン「Blue Hill」出身）
* **Untappd ブルワリー評価**: **4.15**
* **背景**:
  * 料理人出身のBenが「テストキッチン / シンクタンク」をコンセプトに立ち上げた新鋭マイクロブルワリー。
  * ガストロノミー目線の繊細な味覚設計とミニマルな美学が特徴。
* **代表銘柄・注目ビール**:
  * **Tickets To the Sunset**（Hazy DIPA / 8.0% / **Untappd: 4.25**）: トロピカルフルーツとダンク感が絶妙なバランスで溶け合う人気ヘイジー。
  * **The Nature of Water**（Hazy IPA / 6.5% / **Untappd: 4.18**）: 水質調整からアプローチした極めて滑らかでクリーンな飲み口のIPA。
  * **Eternal Echoes**（Experimental Ale / **Untappd: 4.20**）: ワイン酵母やオーク樽のニュアンスを取り入れた料理人ならではの実験作。

### 5. RAR Brewing（アールエーアール / Real Ale Revival）
* **拠点**: メリーランド州ケンブリッジ
* **創業者**: Chris Brohawn, J.T. Merryweather（2013年設立）
* **Untappd ブルワリー評価**: **4.08**
* **背景**:
  * 東海岸チェサピーク湾沿いの港町発祥。全米を熱狂させた**スムージーサワー / ペストリーサワーの元祖「Out of Order (OOO)」シリーズ**の生みの親。
* **代表銘柄・注目ビール**:
  * **Out of Order (OOO) シリーズ**（Smoothie Sour / **Untappd: 4.20〜4.35**）:
    * 例: *OOO: Strawberry Banana Creamsicle*、*OOO: Blueberry Muffin* など
    * 大量の果実ピューレ、マシュマロ、クッキー、バニラを投入したドロドロ食感。もはやビールを超えたフルーティーな飲むデザート。
  * **Pulp**（Hazy IPA / 6.3% / **Untappd: 4.02**）: 絞りたてのオレンジ果汁を思わせるジューシーな看板IPA。

### 6. Messorem Bracitorium（メッソレム・ブラチトリウム）
* **拠点**: カナダ・ケベック州モントリオール
* **創業者**: Sébastien Chaput, Vincent Ménard, Marc-André Filion（全員メタル・ハードコアバンド出身）
* **Untappd ブルワリー評価**: **4.23**
* **背景**:
  * 醸造長のVincentはカナダの伝説的ブルワリー「Auval」「Les Trois Mousquetaires」出身。
  * ラテン語で「死神（Messorem）の醸造所（Bracitorium）」を意味し、カナダ最高峰の評価を受ける。
* **代表銘柄・注目ビール**:
  * **Ces Vipères**（Hazy DIPA / 8.2% / **Untappd: 4.29**）: Citra, Galaxy, Strata, El Doradoホップを贅沢に使用した、濃厚でトロピカルな看板ヘイジー。
  * **Fracturation**（Hazy DIPA / 8.0% / **Untappd: 4.25**）: Citra CryoとSimcoe Cryoホップを効かせた、柑橘と松の鮮烈なアロマ。
  * **Élaborer à 3**（BA Imperial Stout / 11.5% / **Untappd: 4.31**）: Hudson ValleyやObercreekとのコラボによる重厚樽熟成スタウト。
  * **Canal Fatal**（Hazy IPA / 6.0% / **Untappd: 4.13**）

### 7. Ghost Town Brewing（ゴーストタウン・ブルーイング）
* **拠点**: カリフォルニア州オークランド
* **創業者**: Ryan Nosek, Sam Carr-Prindle, Jason Gehman, Adam Hill（ヘッドブルワー: Justin Burdt）
* **Untappd ブルワリー評価**: **3.95**（※WCIPA・ラガー主体としては全米屈指のハイアベレージ）
* **背景**:
  * 元々はバンドの練習スタジオ代を稼ぐための自家醸造からスタート。
  * 全米最大の審査会**GABF（Great American Beer Festival）2022で「Brewery of the Year」を受賞**した超実力派。
* **代表銘柄・注目ビール**:
  * **Nose Goblin**（Imperial IPA / 9.2% / **Untappd: 4.04**）: **GABF最高峰のインペリアルIPA部門で連続金賞**を受賞した伝説のダブルIPA。強烈な松・グレープフルーツ・ダンク香と鮮烈なドライフィニッシュ。
  * **The Grim**（Triple IPA / 10.5% / **Untappd: 4.18**）: モンスター級のホップ量とアルコール度数を誇る重厚なTIPA。
  * **Inhume**（West Coast IPA / 7.0% / **Untappd: 3.88**）: クラシカルかつモダンなホップが冴え渡る王道WCIPA。
  * **Pena Smrti**（Czech Pilsner / 4.4% / **Untappd: 3.85**）: GABFメダル獲得の極上チェコピルスナー。

### 8. Off Script Brewing（オフスクリプト・ブルーイング）
* **拠点**: コロラド州オーロラ / ソーントン
* **創業者 / ブルワー**: Ryan Taylor
* **Untappd ブルワリー評価**: **4.49**（※参加ブルワリー中最高スコア！）
* **背景**:
  * 実店舗のタップルームを持たず、他社醸造設備を間借りして少量生産するナノブルワリー。
  * 「台本通り（On Script）ではない」型破りなアプローチ。
* **代表銘柄・注目ビール**:
  * **Secret Formula**（Cryo Hazy TIPA / 10.2% / **Untappd: 4.52**）: 最新の濃縮CryoホップとHop Kiefを限界まで投入した、ホップの飽和状態（Saturated）を味わえる怪物ビール。
  * **All My Friends**（Hazy DIPA / 8.5% / **Untappd: 4.45**）: 驚くほどクリーミーでジューシーなピーチ・マンゴー・ベリーのアロマ。
  * **Off Script 各種バッチ**（Hazy DIPA / **Untappd: 4.40〜4.55**）: 極小ロットゆえにどれを飲んでもほぼ4.4超え。

### 9. Lyric Brewing（リリック・ブルーイング）
* **拠点**: コロラド州デンバーエリア
* **Untappd ブルワリー評価**: **4.35**
* **背景**:
  * デンバーのNew Image Brewing等の設備を利用して醸造するジプシー/コントラクト形態のナノブルワリー。
  * アングラな存在感を保ちつつ、一口飲めばわかる圧倒的な果汁感と芳醇なホップアロマでカルト的人気を誇る。
* **代表銘柄・注目ビール**:
  * **Words Unspoken**（Hazy TIPA / 10.0% / **Untappd: 4.42**）: マンゴーピューレのような濃厚なテクスチャとフルーティーなホップ爆弾。
  * **Poetry in Motion**（Hazy DIPA / 8.4% / **Untappd: 4.38**）: 滑らかなオーツの口当たりとパッションフルーツの芳醇なアロマ。
  * **Acoustic Echoes**（Hazy IPA / 7.2% / **Untappd: 4.30**）

### 10. Tall Trees Brew Lab / Tall Trees Brewing（トールツリーズ）
* **拠点**: オレゴン州ヒルズボロ
* **創業者**: Dan Schlegel, Nathan Roszina
* **Untappd ブルワリー評価**: **4.34**
* **背景**:
  * ホームブルーイング仲間が2019年から立ち上げた新鋭ブルワリー/ラボ。
  * ポートランド近郊のローカル原料やフレッシュなホップを活かした丁寧なクラフトマンシップ。
* **代表銘柄・注目ビール**:
  * **Forest Floor**（Hazy DIPA / 8.2% / **Untappd: 4.35**）: 地元オレゴン産のフレッシュなホップをブレンドした、青々とした柑橘とジューシーな果実味が共存する名作。
  * **Canopy Walk**（West Coast DIPA / 8.0% / **Untappd: 4.20**）: パイン（松）と樹脂、ダンクなアロマが心地よい力強いダブルWCIPA。
  * **Lab Series 各種**（Small Batch Hazy / **Untappd: 4.30〜4.40**）: 実験ロットとして仕込まれるスモールバッチヘイジー。

## 当日のスタイル別・立ち回りメモ

* **最高峰のHazy IPA / TIPAを攻めるなら**

### ペース配分・コンディション管理

1. **度数（ABV）の高さに注意**: Hazy DIPA/TIPAやインペリアルスタウトは8〜10%超が基本。フリーフローだからと最初から飛ばすと早い段階で味覚と身体がやられる。
2. **Everywhereのラガーとお水をチェイサーに挟む**: 舌がホップで飽和してきたら、お水だけでなくEverywhereの綺麗なラガーを挟むとリフレッシュできる。
3. **ブルワーとの対話**: せっかくブルワー本人が注いでくれるプレミアムな場なので、使っているホップや醸造のこだわりを直接聞きながら味わう。
